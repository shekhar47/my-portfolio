# My Portfolio

A modern, scalable, and professional personal portfolio built using **React.js**, **TypeScript**, and **Redux Toolkit**.  
Designed to showcase projects, skills, and experience with clean architecture and best practices.

---

## 🚀 Tech Stack

### Frontend
- React.js
- TypeScript
- Redux Toolkit
- React Router
- SCSS / CSS Modules

---

## 📁 Project Structure

This project follows a **feature-based architecture** for scalability and maintainability.
